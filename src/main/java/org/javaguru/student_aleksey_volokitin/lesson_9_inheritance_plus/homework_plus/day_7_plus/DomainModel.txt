Доменная модель для электронной системы управления библиотекой.

1. Класс Book - книга.
    1.1. Переменные:
        - private int id                        - идентификатор книги
        - private String title                  - название книги
        - private String author                 - автор книги
        - private String bookGenre              - жанр книги
        - private int yearOfPublication         - год издания
        - private double priceOfReading         - цена за прочтение книги
        - private boolean statusOfReserve       - статус резерва книги
        - private boolean issueStatus           - статус выдачи книги
        - private LocaleDate dateOfIssue        - дата выдачи книги
        - private LocaleDate dateOfReturn       - дата возврата книги
        - private int idReader                  - идентификатор читателя, получившего  книгу
        - private int idIssueLibrarian          - идентификатор библиотекаря, выдавшего книгу
        - private int idReturnLibrarian         - идентификатор библиотекаря, принявшего книгу
        - private List<Integer> idsOfReader     - список идентификаторов читателей, получавших книгу
    1.2. Конструктор:
        - id                                    = следующий порядковый номер
        - title                                 - вводимый параметр
        - author                                - вводимый параметр
        - bookGenre                             - вводимый параметр
        - yearOfPublication                     - вводимый параметр
        - statusOfReserve                       = false
        - issueStatus                           = false
        - dateOfIssue                           = null
        - dateOfReturn                          = null
        - idReader                              = 0
        - idIssueLibrarian                      = 0
        - idReturnLibrarian                     = 0
        - idsOfReader                           = new ArrayList()
    1.3 Методы:
        - addBook(вводимые параметры)           - добавление новой книги
        - correctionBook(id)                    - корректировка данных о книге
        - deleteBook(id)                        - удаление книги
        - findBook(список параметров)           - поиск книги по заданным условиям
        - printListOfReaders(id)                - отображение списка читателей, получавших книгу
        - reserveBook(id)                       - постановка книги в резерв
        - issueBook(id)                         - выдача книги
        - returnBook(id)                        - возврат книги

3. Класс Reader extends Person - класс читателей
    3.1. Переменные:
        - private boolean statusOfReader        - статус, является ли человек читателем
        - private sumOfFines                    - сумма назначенных штрафов
        - List<Book> books                      - список книг, которые получал читатель
    3.2. Конструктор:
        - super (
            - id                                = следующий порядковый номер
            - lastName                          - вводимый параметр
            - firstName                         - вводимый параметр
            - patronymic                        - вводимый параметр
            - tel                               - вводимый параметр
            )
        - statusOfReader                        = true
        - sumOfFines                            = 0
        - List<Book> books                      = new ArrayList()
    3.3. Методы:
        - addReader(вводимые параметры)         - добавление читателя
        - correctionReader(id)                  - корректировка читателя
        - deleteReader(id)                      - удаление читателя
        - findReader(список параметров)         - поиск читателя по заданным параметрам
        - printListOfBook()                     - отображение списка книг, которые получал читатель
        - printListOfIssuedBook()               - отображение списка книг, которые находятся у читателя
        - payingPriceOfReading(id книги)        - оплата за использование книги
        - payingFines()                         - оплата штрафов

        - List<Book> issuedBooks                = new ArrayList()

    4.3. Методы:

        - correctionLibrarian(id)               - корректировка библиотекаря
        - deleteLibrarian(id)                   - удаление библиотекаря
        - findLibrarian(список параметров)      - поиск библиотекаря по заданным условиям
        - printListOfIssuedBook()               - отображение списка книг, которые выдавал библиотекарь
        - printListOfReturnedBook               - отображение списка книг, которые принимал библиотекарь

5. Класс Library - библиотека.
    5.1. Переменные:
        - private String name                   - название библиотеки
        - private String address                - адрес библиотеки
        - private String tel                    - номер телефона
        - private String email                  - адрес электронной почты
        - private List<Book> books              - список книг в библиотеке
        - private List<Reader> readers          - список читателей
        - private List<Librarian> librarians    - список библиотекарей
        - private List<Reader> listOfSendEmails - список читателей для рассылки сообщений о сдаче книги
        - private List<Reader> listOfFinedReaders - список читалелей, которым назначен штраф
    5.2. Конструктор:
        - name                                  - вводимый параметр
        - address                               - вводимый параметр
        - tel                                   - вводимый параметр
        - email                                 - вводимый параметр
        - List<Book> books                      = new ArrayList()
        - List<Reader> readers                  = new ArrayList()
        - List<Librarian> librarians            = new ArrayList()
        - List<Reader> listOfSendEmails         = new ArrayList()
        - List<Reader> listOfFinedReaders       = new ArrayList()
    5.3. Методы:
        - sendEmailsAboutReturnBooks()          - рассылка оповещений читателям о сроке сдачи книги
        - assignmentFines()                     - назначение штрафов за вовремя не сданные книги
