Какое из решений вам кажется лучше и почему?
Приведите конкретные аргументы за и против,
плюсы и минусы для каждого решения.


Мой вариант использует начальные конструкторы для объектов, подъобъектов и полисов.
Решение ментора создает вспомогательные конструкторы для создания новых объектов.

Плюсы моего решения: код в моменте быстрее пишется (в лоб).
Минусы моего решения: всегда придется дополнительно создавать списки и биг десимал, сложнее читать код.

Плюсы решения ментора: вспомогательные конструкторы в будущем при создании многих объектов упростят эту задачу, код читабельнее.
Минусы решения ментора: необходимо потратить время на создание вспомогательных конструкторов, код больше.
